# Трекер привычек для iPhone

Приложение работает без сборки и внешних библиотек. Для размещения нужны все файлы этой папки, включая `assets` и скрытый файл `.nojekyll`.

## Размещение на GitHub Pages

1. Создайте репозиторий GitHub и загрузите содержимое этой папки в корень ветки `main`. Загружайте сами файлы, чтобы `index.html` оказался в корне репозитория.
2. Откройте **Settings > Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main** и папку **/(root)**. Нажмите **Save**.
3. Дождитесь завершения публикации. Откройте адрес HTTPS из раздела Pages, например `https://username.github.io/repository/`.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Установка на iPhone

1. Откройте адрес опубликованного приложения в Safari.
2. Нажмите **Поделиться > На экран «Домой»**. Если доступен переключатель **Открывать как веб-приложение**, включите его. Нажмите **Добавить**.
3. Запустите приложение с домашнего экрана при включенном интернете и дождитесь загрузки. Ведите записи из установленного приложения. После успешного первого кеширования основные функции доступны без сети.

[Инструкция Apple](https://support.apple.com/guide/iphone/bookmark-a-website-iph42ab2f3a7/ios). [Документация WebKit о веб-приложениях на домашнем экране](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).

## Данные и напоминания

Данные сохраняются локально в браузере этого устройства. Используйте экспорт JSON в приложении для резервной копии и импорт для восстановления. Установка на другом устройстве или очистка данных сайта не переносит записи автоматически. Перед очисткой сайта сохраните экспорт.

Статическая версия показывает напоминания внутри открытого приложения. Она не планирует системные уведомления при закрытом приложении. Push-уведомления при закрытом приложении потребуют отдельного сервера и разрешения пользователя.

## Обновления и проверка

После изменения файлов обновляйте `VERSION` в `sw.js`. Новый кеш устанавливается только после успешной загрузки всех основных файлов. Закройте все окна приложения и откройте его снова, чтобы активировать обновление.

После публикации откройте приложение, создайте привычку, перезапустите его и проверьте сохраненную запись, экспорт JSON и работу после отключения сети. Для локальной проверки используйте HTTP-сервер на `localhost`.
